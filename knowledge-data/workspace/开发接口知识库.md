# 开发接口知识库

本文件描述当前 AI Knowledge Hub 已实现的 HTTP 接口。业务接口位于 /api 下，普通 JSON 响应具有 code、message、data、timestamp 四个字段；文件下载与 SSE 流使用各自协议。

## 身份认证

POST /api/auth/login 接收 JSON 字段 username 和 password，成功后在 data 中返回 token 与 user。后续请求在 Authorization 请求头携带 Bearer 加空格加令牌。GET /api/auth/me 获取当前用户。POST /api/auth/logout 注销登录令牌。

PUT /api/auth/profile 接收 nickname 更新昵称。PUT /api/auth/password 接收 currentPassword 和 newPassword 更新密码，密码变更使旧令牌失效。401 表示需要登录，403 表示没有访问权限，404 表示对象不存在，409 表示操作冲突，429 表示请求过于频繁。

## 知识库与文档

GET /api/knowledge-bases 返回有权访问的知识库，可传 keyword 搜索名称。POST /api/knowledge-bases 接收 name 与 description 创建知识库。GET、PUT、DELETE /api/knowledge-bases/{id} 分别读取、更新和删除指定知识库。

GET /api/knowledge-bases/{id}/documents 获取文件列表。POST 同一路径上传文件，采用 multipart/form-data，字段名为 file，响应 HTTP 202 表示已接收异步处理任务。客户端轮询 GET /api/documents/{id}，直到状态为 SUCCESS 或 FAILED。

GET /api/documents/{id}/chunks 返回文本片段。GET /api/documents/{id}/download 下载原文件，下载也需要 Authorization。POST /api/documents/{id}/reindex 重新索引。DELETE /api/documents/{id} 将文档移入回收站；POST /api/documents/{id}/restore 恢复文档，版本冲突返回 409。GET /api/documents/{id}/versions 查看版本，POST 同一路径以 file 字段上传新版本。

## 流式问答

GET /api/chat/stream 接收 knowledgeBaseId、question 与可选 sessionId，返回 text/event-stream。question 不可为空且最多 4000 字符。使用支持 Authorization 请求头的 fetch 流式读取；跨知识库或他人的 sessionId 会被拒绝。

SSE 事件用空行分隔。message 事件的 data 是答案片段，应按到达顺序追加；citation 事件包含文档 ID、名称、页码、片段 ID 和摘录；meta 事件包含 sessionId、mode 及检索信息 retrieval（简单寒暄无检索信息）；done 事件表示完成，data 是统一 Result 包装的会话 ID；error 事件表示失败。以冒号开始的行是注释，不应显示为答案。

网络分块可能截断事件行，客户端必须缓存不完整事件，并使用流式 UTF-8 解码。连接结束但没有 done 或 error 时，不能假设回答完整。AbortController 可以中断连接。

## 管理与统计

GET /api/chat/sessions 获取当前用户会话，GET /api/chat/sessions/{id}/messages 获取消息及引用，DELETE /api/chat/sessions/{id} 删除会话。GET /api/dashboard/overview 读取按权限统计的概况，GET /api/system/status 返回语言模型、Embedding、向量存储与 Redis 配置模式。

/api/admin 下的用户管理、日志和统计接口需要管理员角色。服务端每次请求核对数据库中的账号状态和角色，前端隐藏按钮不能替代服务端鉴权。
