# 阅读体验设置

本轮仅实现三项体验优化，保留水墨山河、书本布局及业务功能。

- **纸面 85%**：使用纸面背景颜色的 alpha，文字、按钮与表单不随容器降低不透明度。翻页副本临时使用不透明纸面，避免两层正文透叠。
- **翻页速度**：顶部提供舒缓（1500ms）、快速（600ms）和关闭动画；同时影响开书和路由翻页。系统“减少动态效果”优先于速度设置。
- **专注阅读**：隐藏章节装饰与书签栏，扩展正文，淡化山河背景。顶部保留设置和退出入口，通过导航按钮打开原有导航面板；支持 Escape 关闭和焦点恢复。

速度与专注状态通过 `readingPreferences.ts` 存入浏览器本地 `ai_kh_reading_preferences`。首次默认舒缓、非专注；无效数据回退默认值。保存失败时设置仍在本次会话生效，并显示提示。设置属于当前浏览器，不与账号同步。

验证：149 项前端测试与生产构建通过。模拟接口浏览器检查覆盖桌面 1440×900、手机 390×844、设置刷新恢复、快速/关闭动画、导航键盘交互和无横向溢出。桌面专注正文宽度由约 681px 增至 1280px。
