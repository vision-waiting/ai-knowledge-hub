# 知识库功能扩展

## 使用入口

| 入口 | 功能 | 权限 |
| --- | --- | --- |
| `/search` 全文搜索 | 文档正文搜索、文件名/类型/标签过滤、分页、原文定位 | 知识库读者 |
| 问答消息下方 | 点赞、不满意及原因；历史消息保留反馈 | 会话本人 |
| `/workspace` 知识维护 | FAQ、术语别名、阅读顺序；反馈处理；团队成员 | 内容可读；维护需管理权限 |
| 文档管理 | 上传新版本、查看历史、回收站与恢复 | 读者可看，编辑者可修改 |
| `/retrieval` 检索实验室 | 查看召回片段和分数，导入问题集，对比 topK，导出结果 | 管理者 |
| `/web-sources` 网页资料 | 导入公开 HTTPS 网页、手动检查正文变化并生成版本 | 编辑者 |
| 学习助手 → 加入复习计划；`/review-plan` | 到期卡片、展示答案、自评后安排下次复习 | 学习记录本人 |

成员角色：VIEWER 可读，EDITOR 可维护文档，MANAGER 可管理知识库内容、反馈和成员。知识库所有者和系统管理员保留管理权限。取消成员后，私有知识库访问立即失效；共享库仍可按共享规则阅读。

## 文档与历史

新版本完成索引后才替换当前版本；处理失败时旧版本继续提供检索。已成功文档重新索引也会创建版本。旧版本保留原文件和切片，历史问答引用及学习记录仍可访问。归档和回收站文档不会参与新问答与全文搜索。恢复文档时如已有当前版本或处理中版本，会提示冲突。

删除单个文档进入回收站；删除整个知识库仍为永久删除。请在生产升级前备份数据库与上传目录。启动迁移只增量添加表和字段，不清空现有数据；完整结构见 `sql/schema.sql`，版本字段另见 `sql/versions.sql`。

## 依赖和配置

网页导入需要运行环境提供 curl，可用 `CURL_COMMAND` 指定可执行文件。只支持公开 HTTPS、443 端口及静态 HTML，最多 2MB；不支持登录、验证码或 JavaScript 动态渲染。DNS 地址与每次重定向都会检查，连接固定到已验证的公网地址。

PDF 无文本页可使用 Tesseract OCR。默认本地不启用；安装 Tesseract 和所需语言包后设置：

```powershell
$env:OCR_COMMAND='C:\Program Files\Tesseract-OCR\tesseract.exe'
$env:OCR_LANGUAGES='chi_sim+eng'
```

仅对没有可提取文本的页面执行 OCR，保留页码；单文档最多 100 个 OCR 页面，单页超时 45 秒。运行时 Dockerfile 已加入 curl、Tesseract 和中文语言包。本次未验证 Docker 镜像构建，也未以真实 Tesseract 验证中文识别质量。

## 能力边界

- 全文搜索使用有数量限制的 SQL 文本查询，尚未接入倒排索引/BM25；大规模语料需要独立搜索引擎。
- FAQ、术语别名和阅读顺序作为人工维护内容展示，尚不自动入向量索引或扩展查询。
- 检索评测提供 hit@K、片段排名 MRR、文档召回率、无答案问题拒绝率与耗时；它不是生成答案质量评分。问题集应使用当前知识库真实文档 ID。页面最多保留最近 10 次运行，刷新后清空，可导出 JSON。
- 网页更新由用户手动检查，无后台定时同步。
- 间隔复习面向知识卡片，错题练习仍使用原有入口。AGAIN 为 10 分钟，GOOD/EASY 按当前间隔递增。
- OCR 不是复杂表格或版面理解；图片与文本混排页面中的图片文字不会单独识别。
- 独立语义重排模型、GraphRAG、Agentic RAG 尚未实现，不据此宣称准确率提升。
