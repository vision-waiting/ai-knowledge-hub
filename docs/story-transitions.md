# 右上角卷页转场

## 参考与选择（2026-10-27）

- Apple Books 官方指南提供 Curl、Fast Fade 和 Scroll 三种翻页模式：https://support.apple.com/en-ie/guide/iphone/iphc1af7c57/27/ios/27
- Kobo 官方阅读应用介绍支持自定义 page turns：https://www.kobo.com/us/en/p/apps
- 本项目选取 Curl 的纸页折叠视觉，并按用户要求固定从右上角掀起。右上角起点和 1500ms 时长是本项目设计选择，不声称是上述软件的统一默认值。

## 当前行为

登录成功、工作区路由切换默认使用 1500ms 卷页，可在顶部阅读设置切换为快速 600ms 或关闭动画。右上角先形成折角，折痕向左下移动，纸页背面和双层阴影一起移动，露出已经挂载的新页面。保留旧正文直到折痕经过，不再提前擦去正文，也不再混用暗幕字幕、光带和中心开窗。末尾 10% 淡出剩余旧画面。封面开书保持硬封面绕书脊打开，遵循同一速度设置，整体开场增加 100ms 收尾；关闭动画时直接进入。

`storyTransition.ts` 提供统一计划；`enterWorkspace.ts` 管理旧页面副本、右上角折线几何、动画和清理。`book.css` 提供卷页阴影，`ink.css` 在转场期间令旧页面副本不透明，避免两页文字透叠，正常书页仍使用当前透明度。

## 交互与边界

- 副本对辅助技术隐藏且不可交互；复制前清除密码值。
- 新页面先导航再揭示，不等待业务请求，不伪造加载完成。
- 保持嵌套滚动位置；只绘制视口内的卷页部分。
- Esc、窗口缩放、切换减少动态效果、后续导航可取消动画。
- 减少动态效果时直接导航；动画 API 不可用或出错时仍清理副本并恢复交互。
- 完成后焦点转移到目标页标题；同路由参数变化沿用路由器的跳过规则。

前端全量 39 个测试文件、149 项测试及生产构建通过。浏览器以模拟接口验证 600ms 翻页、关闭动画、刷新后设置保留、导航焦点恢复及手机无横向溢出；不代表后端联调成功。截图位于本地忽略的 `output/` 目录。
